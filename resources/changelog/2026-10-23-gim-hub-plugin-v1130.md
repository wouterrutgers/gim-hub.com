# GIM Hub plugin v1.13.0

- Added coin tracking for the Blast Furnace, Nightmare Zone, and Scar Essence Mine coffers.
- Fixed incorrect bank counts after bulk inventory and equipment deposits.
- Fixed tracking for degraded giant essence pouches and equipped fish sack barrels, including the bank's **Deposit containers** action.
- Fixed an error when mining with a coal bag before checking its contents.
- Fixed partial bank updates being lost when several changes were queued for upload.
- Fixed collection log tracking getting stuck after logging out in Chambers of Xeric.
- Fixed activity updates being rejected when the system clock moved backwards.
- Reduced unnecessary storage updates to improve plugin performance.
