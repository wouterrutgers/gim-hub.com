# Mobile, activity and classic theme updates

- Added **Timeline** and **Compare** views to the **Activity** page.
- Refreshed the activity page and sidebar with clearer player names, timestamps, filters, and expandable activity rows.
- Improved mobile activity comparisons with a fixed activity column and horizontal scrolling between players.
- Added item icons to ordinary activity drops as well as new collection log unlocks.
- Fixed group bank items being out of reach in landscape mode. Selecting an item in **Compact** view now brings its details into view too.
- Improved mobile navigation with a scrollable **More** menu and top tabs on short landscape screens. Navigation tooltips no longer appear on mobile.
- Map search results now fit in the available space above the mobile keyboard. Selecting a location closes the keyboard.
- Player panels now use the full width on mobile, and combat achievement tiers fit better on small screens.
- Added **Apply classic settings** in **Settings** to enable detailed items, collapse desktop navigation, and set background opacity to 90%.
- Fixed the **Your group** header staying black at 0% background opacity in classic themes.
- Moved player selection to a dedicated **Your player** section at the top of **Settings** and removed the extra preference status message.
- Fixed XP drops staying on screen when reduced motion was enabled.
- Removed the obsolete **Tutorial** quest category.
- Corrected imported Sailing XP incorrectly starting at 1 instead of 0, including affected history.
